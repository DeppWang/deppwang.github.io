用 DashPlayer 看美剧学英语

发表于 2026-10-27 | 更新于 2026-10-28 | | 阅读次数

最近在用 DashPlayer 看《绝命毒师》学英语，体验下来觉得还可以，推荐给也想用本地视频、音频学英语的朋友。软件开源免费，可以控制字幕显示，也方便反复听一句台词。

它支持 Windows 和 Mac，我自己用的是 Mac，下面就按我在 Mac 上的使用方式来写。

先到官方下载页面，展开 Assets，找到适合自己电脑的安装包。Mac 下载以 .dmg 结尾的文件，M 系列芯片选 arm64，Intel 芯片选 x64，不要下载 Source code，那是源代码。下载后打开，把 DashPlayer 拖进 Applications 文件夹就可以了。安装说明。

接下来准备视频和对应的字幕文件。我现在用的是《绝命毒师》，一般是在猫狸盘搜中找资源，目前我找到的资源只有「迅雷云盘」中有。《绝命毒师》具体资源链接。

DashPlayer 的按句播放等操作需要用到字幕文件，所以最好找到和视频对应的字幕。如果没有的话也可以用 AI 生成，但我还是更想用现成的翻译字幕，所以在 assrt.net 中找了对应的字幕文件。

准备好后，在 DashPlayer 里通过「打开文件」选择视频和字幕。不过，我偶尔会碰到打开视频后，再打开字幕没有反应的情况，还没确定是什么原因。

字幕文件准备好了，还有一个问题：视频画面里本身就带着中英文字幕，在播放器里关字幕也去不掉。我想练英语，希望视频不要带中文字幕，但找了很久没找到合适的版本，就想到一个曲线救国的办法：用字幕遮挡工具，把画面里的中文字幕挡住。

这个字幕遮挡工具叫 Menu Bar Cover。也是需要你下载安装的。它默认是菜单栏遮挡，使用这个快捷键 Cmd + Option + M 切换到字幕遮挡。

通过快捷键调整遮挡的高度、宽度和位置，就可以把画面里的中文字幕挡住。

不过，Menu Bar Cover 我用着偶尔会碰到 D 键失灵，退出遮挡工具后才能恢复。

我一般会先正常开着中英文字幕看一遍，第二遍再专门拿来学英语。第一遍先把剧情看了，第二遍就不会一直被剧情吸引，可以把注意力放在台词上。我配置跳过没有台词的部分，专门听有对话的地方。

界面上，我会关掉侧面的字幕列表，只留下方的字幕条，设置成只显示英文。快捷键切换字幕很方便，我常用 B 键来显示或隐藏字幕。

遇到不认识的单词，也可以用它的查词功能。当前版本已经内置离线常用词词典，不配置 API Key 也能查基本释义；AI 查词、字幕翻译和整句学习等功能，则需要另外配置 AI 接口。软件免费，自己接入的 AI 服务可能会收费，具体配置可以看官方说明。

如果不想坐在电脑前看视频，只想听听台词，也可以用「每日英语听力」。我也让 AI 生成了一些《绝命毒师》的对白听力内容，把链接放在下面，想纯听英语的朋友也可以直接听。
