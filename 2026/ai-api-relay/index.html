为什么中转站的 API 这么便宜

发表于 2026-11-20 | 更新于 2026-11-20 | | 阅读次数

有些 AI 中转站提供的 API，价格比官方 API 便宜很多。同样是使用 GPT 模型，中转站的价格为什么能低这么多？我算了一下官方订阅的额度，发现如果能把额度用完，成本确实可以很低。

现在很多 Codex 中转站，都是把官方订阅额度转换成 API 来卖。官方订阅每个月付固定费用，账号在每个周期内可以使用一定的额度。中转站把这些账号接入自己的服务，让用户通过 API 调用，尽量把每个周期的额度都用完。

以一个每月 200 美元的美区订阅账号为例，假设每周用量按官方 API 价格计算，相当于 1,353 美元。如果每周额度都用完，按每月 4 个周期算，一个月就相当于用掉 5,412 美元的 API 额度。

200 美元的订阅费，除以 5,412 美元的额度，约等于 3.7%。也就是说，官方 API 标价 1 美元的用量，订阅费分摊下来只需要约 0.037 美元。按 1 美元兑换 6.79 元人民币算，大约是 0.25 元，相当于花两毛多钱就用到了官方 API 标价 1 美元的用量。

如果某个模型的官方 API 输入价格是每百万 Token 2 美元，按照同样的比例算，订阅费分摊下来约是 0.074 美元，也就是 0.50 元人民币左右。这样看，即使中转站卖得比官方 API 便宜很多，也可能有空间覆盖成本。

我看到的一些 Codex 中转渠道，价格大约是官方 API 价格的 7%，也就是 0.7 折。按上面的汇率算，官方 API 标价 1 美元的用量，中转站大约收 0.48 元人民币。跟前面算出的 0.25 元订阅费用相比，中间还有一些空间。当然，不同中转站、不同分组的价格不一样，有的标的是站内倍率，还需要结合充值和扣费规则换算，才能知道实际相当于官方价格的多少。

按这个价格算，GPT-6.2 Sol 的中转 API 甚至可能比国内的 DeepSeek V4 Pro 官方 API 还便宜。以每百万 Token 为单位，GPT-6.2 Sol 的官方 API 标价是输入 2 美元、输出 10 美元；按 7% 和上面的汇率换算，中转价格大约是输入 0.95 元、输出 4.75 元。而 DeepSeek V4 Pro 官方 API在空闲时段的价格是输入 4.5 元、输出 13.5 元，高峰时段还要翻倍。

这里比较的是相同 Token 数量下的单价。GPT-6.2 Sol 和 DeepSeek V4 Pro 的能力表现还要看具体任务，完成同一件事消耗的 Token 也可能不同，所以不能仅凭单价判断实际任务的总费用。不过，如果中转站确实提供的是标称模型，这样的价格对比还是挺有意思的。

这笔账有个前提：每周额度都能用完，而且对应模型的用量可以按同一方式换算。1,353 美元是按 API 价格估算的用量价值，具体模型的额度消耗可能不同。中转站除了订阅费，也还有账号和服务运行等成本。

如果碰到额外的额度重置，或者官方有活动，一个月能用的额度更多，分摊下来的成本还可能更低。比如能用满 5 个周期，订阅费就约相当于官方 API 价格的 3%。

我还看到有些 Codex 中转渠道，售价甚至低于上面算出的订阅成本。这是怎么做到的，我现在也不能确定。可能是它们通过其他地区的订阅或活动，以更低的价格获得账号，甚至有些账号的会员成本接近于零。也可能存在掺假的情况，用更便宜的模型冒充标称的模型。

这些都只是可能性，不能光看价格就认定某个中转站用了哪种方式。不过，算完这笔账以后，我对中转站为什么能把 API 卖得这么便宜，有了一个更直观的理解：如果一个订阅账号的额度能被充分用起来，按每次调用分摊的订阅费用，确实可以远低于官方 API 的标价。
